# SparkleCore

Note I am not a hard core programmer, i am just a extreamly peed off rtole play enjoyer that wanted a solution that works for what i like to do.

This project was created as a personal solution to a frustrating problem: online chatbots that constantly suffer from memory amnesia and charge expensive monthly fees. SparkleCore was built as a completely free, offline-first alternative designed to never forget you or your adventures.



SparkleCore is a local-first neural roleplay studio uniting LLM inference with cognitive MemPalace (Method of Loci) long-term memory, narrative RPG quests, real-time character vitals, keyword LoreBooks, and full-fidelity local server integrations.

## Quickstart


Follow these steps to run SparkleCore locally:


1. **Clone or download** the repository:
   ```bash
   git clone [https://github.com/GoatymcGoatFace/SparkleCore.git](https://github.com/GoatymcGoatFace/SparkleCore.git)
   cd SparkleCore
   or
   Top right Green code button,
   click and select download ZIP,
   extract the zip file and open the folder,
   right click inside the folder and select open terminal,
   open konsole or open console



2. **Install dependencies**:
```bash
npm install



```
3. **Build the assets**:
```bash
npm run build

```


4. **Start the application server**:
```bash
npm run serve -- --port=3000

```


5. **Launch the interface**:
Open [http://127.0.0.1:3000/](https://www.google.com/search?q=http://127.0.0.1:3000/&utm_source=gemini) in your browser.

## Core Features


### Models & Inference
* **Multi-Provider Neural LLM Inference** `[active]` — Seamless support for Google Gemini, local offline engines, and OpenRouter cloud aggregators.
* **Real-Time Streaming & Latency Telemetry** `[active]` — Chunked token delivery with millisecond Time-To-First-Token (TTFT) and speed gauges.
* **Model Auto-Discovery & Resilient Failover** `[active]` — Automated engine health pinging with transparent fallback to default models.
* **Thinking Mode & Chain-of-Thought Budgets** `[ready]` — Control explicit reasoning budgets for Gemini thinking models.
* **Decoupled Neural Dispatcher & Sub-Models** `[active]` — Assign standalone specialized models to the Quest Engine and Character State & Mood evaluation.

### Memory & Recall
* **MemPalace: Method of Loci Spatial Memory** `[active]` — Cognitive episodic memory graph organizing character memories into architectural rooms.
* **Automated Episodic Fact & Bond Extraction** `[operational]` — Synthesizes key dialogue milestones into long-term memory nodes automatically.

### Roleplay Engine & Interface
* **Virtualized Chat Pagination & History** `[active]` — High-performance dynamic message rendering with seamless chronological lazy loading.
* **Intelligent PDF & DOCX Chat Import Engine** `[active]` — Direct browser-based extraction of rich-text chat logs (PDF, DOCX) with implicit speaker and dynamic action parsing.
* **Roleplay Identity Binding & Strict Dialogue/Action Formatting Engine** `[active]` — Strict binding of 'character' to active chat character and 'user' to active user persona, with universal dialogue (" ") and thought/action (* *) enforcement.
* **Complete Character Bundle Export & Dependency-Rebuilding Import** `[active]` — Export 100% of character-linked data in a unified bundle; import auto-creates missing scenarios, lorebooks, and memories.
* **Interactive PDF Chat Transcript Export** `[active]` — Export rich, beautifully styled conversational transcripts into easy-to-read PDF documents with complete end-of-session vitals and relationship intelligence.
* **Three-Stage Isolated Inference Pipeline** `[active]` — Modular three-stage dialogue lifecycle with pre-inference context, pure streaming, and post-inference quest resolution.
* **Custom Chat Theme & Visual UI Personalization** `[active]` — Interactive chat theme simulator with granular bubble colors, border geometry, density, and atmospheric presets.
* **High-Fidelity Character Personality Engine** `[active]` — Deep persona profiles with avatars, backstories, speech patterns, and custom instructions.
* **User Persona & Identity Matrix** `[active]` — Universal user identity injected across all characters and scenarios.
* **Dynamic Vitals, Affection & 100+ Mood Palette** `[active]` — Living character vitals with real-time sentiment transitions, composure tuning, and 100+ emotional presets.

### Quests & Game Mechanics
* **Narrative RPG Quests & Automated Chat Sync** `[active]` — Turn chats into engaging stories with dynamic character quests, verbal acceptance, and automated dialogue objective checks.
* **Persistent Inventory & Player Game State** `[active]` — Collect items, artifacts, and keepsakes earned through roleplay accomplishments.

### Lore & World Info
* **World Info & Keyword LoreBook Engine** `[active]` — Dynamic worldbuilding encyclopedia with keyword triggers, AI entry generation, and granular entry management.
* **Interactive Scenarios & World Presets** `[active]` — Pre-crafted environmental scenes, atmospheric parameters, AI scenario generation, and lifecycle management.

### Events & Injections
* **Dynamic Roleplay Events & Injections** `[active]` — Inject spontaneous atmospheric dilemmas, NPC arrivals, and twists into the next turn.
* **Multi-Variation Generation & Swiping** `[active]` — Generate multiple responses, swipe between variations, or trigger creative alternative takes.

### Samplers & Tuning
* **Comprehensive Inference Sampler Controls** `[active]` — Fine-tune Temperature, Top-P, Top-K, Min-P, Repetition Penalty, and Context Clamping.

### Diagnostics & System Health
* **Full-Stack System Status & Health Diagnostics** `[active]` — Real-time engine health checks, live latency benchmarks, and active-only interface validation.
* **Concurrency Locks & Schema Resilience Suite** `[active]` — Automated test suite validating atomic file locks, JSON schemas, and session restoration.
* **Process Memory & Disk Quota Limit Monitors** `[active]` — Live V8 heap memory meters and configurable storage warning thresholds.
* **Zero-Telemetry Data Privacy & Backup Management** `[active]` — 100% local persistence with portable JSON backups and selective purge controls.
* **Active Chat Model Censorship Testing** `[active]` — Roleplay-specific censorship and safety policy detection.
